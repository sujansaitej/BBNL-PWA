PDF 1.1 Internet Module Add User - Document Scan Stuck on "Starting camera" on Samsung Galaxy M51
Severity: High Status: Fixed Module: Internet / Add User / KYC Target Device: Samsung Galaxy M51
Issue: Opening document capture from the in-page camera modal could remain stuck on Starting camera... instead of transitioning to a live preview.

Summary

The in-page camera startup flow was too device-sensitive for Samsung Galaxy M51. The modal could remain in initialization instead of completing a clean navigator.mediaDevices.getUserMedia() start and rendering live video frames.

Files changed

  • src/hooks/useCamera.js
  • src/components/PhotoCaptureModal.jsx
  • src/pages/UploadDocuments.jsx

Fix summary

  • Camera startup now uses a direct navigator.mediaDevices.getUserMedia()-first flow.
  • Back camera is preferred first using facingMode: environment.
  • If back camera startup fails, the flow falls back to front camera and then to generic video.
  • Explicit startup timeout and ready-frame timeout prevent silent hangs on Starting camera....
  • Retry now fully stops the previous stream before requesting a new one.
  • Media tracks are stopped on retry, close, and unmount.
  • Uploaded Documents camera modal title mapping was corrected to match the selected proof type.
Risk: Low to medium. The fix is limited to the in-page camera capture flow. Registration API upload behavior and KYC submission contracts remain unchanged.
Validated build: Production build passed after the camera-flow fix.
